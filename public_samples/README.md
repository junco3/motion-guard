inputs. `generated.mp4` is the corresponding real LTX draft, not the reference
render or an invented successful output. All three retain their original bytes.

10-second character is a different, AI-generated image (OpenAI Codex image tool) and is
excluded from this package; see `../docs/asset-provenance.json`. The output is AI-generated using LTX-2.5;
app Apache-2.0 licensing is not a model-weight license. See `../docs/licenses.md`
and `../docs/T3-model-license.txt` (LTX-2.x terms). Its output clause does not claim ownership of
generated output, while use restrictions and the user's responsibility remain.
No photoreal person's likeness, private credential or account log is included.

general accuracy or a fresh-account reproducibility test. Model weights are not
